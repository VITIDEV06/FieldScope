FIELDSCOPE — REEMPLAZO SEGURO

1) NO BORRES la carpeta customer-installed-base.
2) Cierra el backend y el frontend antes de copiar archivos.
3) Extrae este ZIP.
4) Copia las carpetas backend y frontend sobre tu proyecto actual.
5) Cuando Windows pregunte por archivos con el mismo nombre, elige REEMPLAZAR.

NO reemplaces / NO borres:
- backend\venv
- backend\node_modules
- backend\data\installed_base.db
- backend\data\qvac-cache
- tu archivo .gguf de QVAC
- backend\.env

El ZIP deliberadamente NO incluye installed_base.db ni el modelo GGUF para evitar borrar tus datos o tu cache local.

Después de reemplazar:
cd "C:\Users\jorge\OneDrive\Documentos\customer-installed-base\backend"
venv\Scripts\activate
python -m py_compile ai.py main.py models.py schemas.py prompts.py config.py database.py
$env:QVAC_RPC_INIT_TIMEOUT_MS="120000"
